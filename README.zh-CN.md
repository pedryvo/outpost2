## 🚀 关于项目

本项目使用 **REA** 与 Ghidra 对经典硬科幻即时战略游戏《前哨2》(1997) 的二进制文件 (`Outpost2.exe`) 及资源文件 (`.vol`) 进行逆向工程，使用 **Rust + WebAssembly** 打造零模拟开销、高性能现代浏览器版本，并可一键部署至 Vercel。

源码采用 **GPL-3.0** 开源许可协议 ([LICENSE](LICENSE))。
